
# blacktemple_json

Python-скрипт для экспорта VLESS-конфигураций в JSON и автономную HTML-страницу из подписки на сервис Blacktemple.

## Пару матов от человека
1. 100% нейрослоп, в т.ч. дальнейший текст.
2. Доступна версия для браузера, ознакомьтесь с репозиторием: [https://github.com/sinekdoxa/blacktemple_json_online](https://github.com/sinekdoxa/blacktemple_json_online)

## Возможности

- Получение подписки одним подписанным HTTPS-запросом.
- Экспорт массива отдельных конфигураций Xray.
- Автономная HTML-страница с поиском серверов, копированием VLESS-ссылок и QR-кодами.
- Добавление страны и класса сервера в начало названия профиля: `[ГЕРМАНИЯ · TIMEWEB] Название`, `[WHITELIST] Название`.
- Обработка сохранённых ответов без доступа к сети.
- Автоматическое создание и повторное использование идентификатора устройства.

QR-коды формируются локально и встраиваются в HTML как SVG. Страница не использует CDN, внешние библиотеки или сторонние сервисы генерации QR.

## Требования

- Python 3.10 или новее.
- Зависимости из `requirements-subscription.txt`.
- Действующая ссылка подписки для сетевого режима.

Файлы декомпиляции приложения и заранее подготовленный файл идентификатора не требуются.

## Установка

Скачайте исходные файлы репозитория и выполните в каталоге проекта:

```console
python -m pip install -r requirements-subscription.txt
```

## Использование

### Получение подписки

```console
python subscription_export.py -o output/my-subscription
```

Скрипт запросит ссылку подписки скрытым вводом. Такой способ позволяет не сохранять ссылку в истории команд оболочки.

Ссылку также можно передать аргументом:

```console
python subscription_export.py "https://example.com/sub/YOUR_TOKEN" -o output/my-subscription
```

Будут созданы два файла:

```text
output/my-subscription.json
output/my-subscription.html
```

Откройте HTML-файл в браузере, выберите сервер и скопируйте VLESS-ссылку либо отсканируйте QR-код в VPN-клиенте. Для ссылки «Открыть в клиенте» требуется установленный обработчик протокола `vless://`.

### Экспорт сохранённого ответа

```console
python subscription_export.py --input response.bin -o output/offline-subscription
```

Поддерживаются JSON с массивом `servers`, список VLESS-ссылок и Base64-подписка. В этом режиме сетевые запросы не выполняются и идентификатор устройства не создаётся.

### Параметры командной строки

| Параметр | Назначение |
| --- | --- |
| `url` | Ссылка подписки. Если не указана, используется скрытый ввод. |
| `--input PATH` | Сохранённый ответ для офлайн-экспорта. Несовместим с аргументом `url`. |
| `-o PREFIX`, `--output PREFIX` | Префикс выходных файлов. По умолчанию `output/subscription`. |
| `--identity PATH` | Пользовательский путь к постоянному файлу идентификатора устройства. |
| `--timeout SECONDS` | Таймаут сетевого запроса. По умолчанию 30 секунд. |
| `--listing PATH` | Необязательный листинг для переопределения встроенного ключа подписи. |

Полная справка:

```console
python subscription_export.py --help
```

## Формат JSON и совместимость

JSON содержит массив полных отдельных конфигураций Xray, по одной на сервер. Клиент должен поддерживать импорт такого массива. Единого JSON-формата для Xray, sing-box, Clash/Mihomo и всех графических клиентов не существует.

Если клиент принимает только одну конфигурацию Xray, используйте отдельный объект массива. Для запуска через Xray CLI также требуется отдельный объект, а не весь массив. Если клиент не поддерживает такой JSON-импорт, используйте VLESS-ссылку или QR-код при наличии соответствующей функции импорта.

Каждый профиль содержит локальный SOCKS-вход `127.0.0.1:10808`. Для одновременного запуска нескольких профилей необходимо назначить разные локальные порты.

Поддерживаемые транспорты:

- TCP и raw, включая HTTP header;
- WebSocket;
- gRPC;
- XHTTP;
- HTTPUpgrade.

Поддерживаемые варианты защиты соединения: `none`, TLS и Reality. Для XHTTP требуется совместимая версия ядра Xray. Настройки XHTTP `extra` сохраняются.

Страна и класс берутся из полей `country` и `server_class` исходного JSON. Одинаковые значения не дублируются. Название записывается в `remarks` JSON и в часть VLESS-ссылки после `#`, включая ссылки для копирования и QR. Параметр `fp` отвечает за TLS fingerprint и не изменяется для переименования профиля.

Неизвестные параметры URI, неподдерживаемые транспорты и некорректные данные приводят к ошибке экспорта, а не к молчаливой потере настроек.

## Идентификатор устройства

При первом сетевом запуске создаётся постоянный идентификатор пользователя. Последующие запуски используют тот же файл независимо от расположения скрипта и ссылки подписки.

| Система | Путь по умолчанию |
| --- | --- |
| Windows | `%LOCALAPPDATA%/blacktemple-subscription-export/identity.json` |
| macOS | `~/Library/Application Support/blacktemple-subscription-export/identity.json` |
| Linux | `$XDG_CONFIG_HOME/blacktemple-subscription-export/identity.json`, по умолчанию `~/.config/blacktemple-subscription-export/identity.json` |

Файл состояния хранится отдельно от двух выходных файлов. Не удаляйте его между запусками: новый HWID потенциально может занять дополнительный слот устройства. Точное поведение серверной привязки не установлено.

Для использования существующего идентификатора укажите его явно:

```console
python subscription_export.py --identity /path/to/identity.json -o output/my-subscription
```

Не распространяйте один пользовательский идентификатор вместе со скриптом для всех пользователей.

## Сетевое поведение

- Выполняется один HTTPS GET без автоматических повторов и перенаправлений.
- Используется штатная проверка TLS-сертификатов.
- Максимальный размер ответа составляет 4 MiB.
- Принимаются HTTPS-ссылки без credentials, query-параметров и fragment. Алгоритм подписи для других вариантов не подтверждён.
- Ответ с loopback или unspecified адресом считается заглушкой и отклоняется.
- Запросы к платёжным API, смена ключей и VPN-подключения не выполняются.

Общий ключ протокола подписи встроен в исходный код. Для его обновления можно использовать переменную окружения `BLACKTEMPLE_SIGNING_KEY` или параметр `--listing`. Приоритет: переменная окружения, явно указанный листинг, встроенный ключ. Ключ в распространяемом Python-коде нельзя считать скрытым.

Изменения серверного протокола или ключа подписи могут потребовать обновления скрипта.

## Безопасность

Ссылка подписки, экспортируемые JSON и HTML, QR-коды и файл идентификатора являются конфиденциальными данными. Не публикуйте их в репозитории, не прикладывайте к публичным issues и не размещайте в общедоступных каталогах.

Для публикации проекта достаточно скрипта, файла зависимостей, документации и синтетических тестов. Не добавляйте реальные результаты экспорта и сохранённые ответы подписки.

Параметр `allowInsecure`, если он присутствует в исходной VLESS-ссылке, переносится в TLS-профиль. Перед использованием проверьте, не отключена ли проверка сертификата сервера.

На Windows защита файлов определяется разрешениями NTFS. Вызов `chmod` в скрипте не заменяет настройку ACL.

Используйте инструмент только для подписок, к которым у вас есть разрешённый доступ.

## Тестирование

```console
python -m unittest discover -s tests -p "test_subscription_export.py" -v
```

Тесты проверяют формирование подписи, первый запуск без внешних файлов, сохранение идентификатора, преобразование транспортов, названия профилей, обработку ошибок, экранирование HTML и генерацию QR-кодов.

Тест приватных локальных ответов пропускается, если соответствующие файлы отсутствуют. Остальные тесты используют синтетические данные или подмену сетевого запроса. Реальные запросы к подписке в тестах не выполняются.

## Ограничения

- Успешное получение и экспорт подписки не подтверждают работоспособность VPN-серверов.
- Импорт во все существующие клиенты не гарантируется.
- Идентичность устройства синтетическая и не воспроизводит build-поля реального Android-устройства.
- Запись двух выходных файлов не является транзакцией: ошибка файловой системы может оставить неполный результат.
